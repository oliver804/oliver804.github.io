  1. 01

    Local Route Launcher

    v1.2.0 · macOS 13+ · Windows 10/11 · MIT · 19 Oct 2026

    A native launcher that starts a compatible ChatGPT desktop app with your own HTTP proxy, for that launch only. It uses a proxy you already run; it does not provide one, and it does not touch the system proxy, DNS or routing.

    The interesting part is what it refuses to claim: three connection checks that each state what they measured, a second platform that shares behaviour but no code, and a release that will not publish until both builds pass.
