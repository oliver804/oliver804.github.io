02Selected work

One thing, finished properly

Open source · MIT

macOS 13+ · Windows 10/11 · v1.2.0

Local Route Launcher

A native macOS and Windows launcher that gives a compatible ChatGPT desktop app its own HTTP proxy — without turning on TUN, changing the system proxy, or touching DNS.

Most proxy setups reconfigure the machine. This one reconfigures a single launch. It saves a host and port, starts the app with Chromium’s proxy arguments and the matching HTTP_PROXY, HTTPS_PROXY and ALL_PROXY variables, keeps localhost off the proxy so local tools keep working, and asks the app to close rather than killing it.

That scope is narrower on purpose. A narrower scope is the only reason the result is predictable enough to explain in a report.

  • Settings that belong to one process. Nothing is written to system proxy or DNS. Quit the app, open it through the launcher, and the setting travels with that launch only.
  • Checks that say what they measured. Proxy tunnel reachability, the arguments the running process actually carries, and a TCP connection snapshot. The report states that a snapshot is not proof every child process follows the proxy.
  • Menu bar and system tray. Start, stop and read status without keeping a window open.
  • Two languages, two appearances. English and Simplified Chinese switch instantly and are remembered; light and dark are built in.
