Work

Two public repositories

  1. 01

    Local Route Launcher

    v1.2.0 · macOS 13+ · Windows 10/11 · MIT · 19 Oct 2026

    A native launcher that gives a compatible ChatGPT desktop app its own HTTP proxy — without turning on TUN, changing the system proxy, or touching DNS.

    Most proxy setups reconfigure the machine. This one reconfigures a single launch: it passes the proxy as a Chromium argument and as environment variables, keeps localhost off the proxy so local tools keep working, and reports what it measured rather than whether it “worked”.

  2. 02

    This site

    2026 · hand-written HTML · one stylesheet · no build step

    Five destinations, one CSS file and a self-hosted typeface subset. Apart from two analytics tags — documented, not hidden — it loads nothing from another domain, and no page needs a script in order to render, which is why it will still open in ten years without a toolchain.
