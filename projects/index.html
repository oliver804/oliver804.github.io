Work

Two repositories, both maintained by hand. Each one starts from a specific annoyance rather than a technology, and neither is a demo.

  1. 01

    Local Route Launcher

    v1.2.0 · macOS 13+ · Windows 10/11 · SwiftUI + C# · MIT · released 19 Oct 2026

    A native launcher that gives a compatible ChatGPT desktop app its own HTTP proxy — without turning on TUN, changing the system proxy, or touching DNS. Settings belong to one process tree instead of the machine, and the interface says so.

    The interesting part was not the feature. It was the diagnostics, the second platform and the packaging: three checks that each state what they did not establish, a Windows edition that shares behaviour but not code, and a release that refuses to publish until both builds pass.

    Project notes and screenshots Source Download 1.2.0

  2. 02

    This site

    2026 · HTML · CSS · no build step · no JavaScript · GitHub Pages

    Hand-written HTML and one stylesheet, with a self-hosted typeface subset. No framework, no analytics, no cookies, no third-party requests. The constraint is the point: a site that has to be editable by hand in five years cannot depend on a toolchain that will not exist in five years.
