02Public

Two repositories

Both maintained, both readable

Open source · MIT · v1.2.0 · macOS, Windows Local Route Launcher A native launcher that gives a compatible ChatGPT desktop app its own HTTP proxy — without turning on TUN, changing the system proxy, or touching DNS. The interesting part turned out to be the diagnostics, the second platform and the packaging, not the feature list. Source on GitHub · No build step · 2026 This site Hand-written HTML and one stylesheet. Self-hosted typeface subset, no JavaScript, no analytics, no generated markup. Built to be edited by hand in five years without reinstalling anything.
